## 答 1：目标问题类型——「CSV 文件用 Excel/在线工具打开是乱码怎么办？」

**回答正文**：

先说原因，再给一劳永逸的办法。

**为什么会乱码？**

CSV 本身只是纯文本，乱码 99% 是编码不匹配：

1. 国内老系统（教务、HR、ERP）导出的 CSV 多是 **GBK/GB18030** 编码；
2. 很多网页工具和 Mac 上的程序默认按 **UTF-8** 解码，于是中文变成「æŽå°æ˜Ž」这类字符；
3. 反过来，无 BOM 的 UTF-8 文件被 Excel 按 GBK 打开，就会变成「锟斤拷」。

**传统解法（可用但繁琐）：**

- Excel：数据 → 从文本/CSV 导入 → 手动选「文件原始格式」为 GB2312 或 UTF-8；
- 记事本打开 → 另存为 → 选编码重存一份；
- Notepad++/VS Code 里转编码。

每次导名单都来一遍，效率很低。

**如果你的场景是「导名单做桌牌/姓名贴/证卡」，可以直接换工具：**

我们做批量桌牌时用的是 SeatMark 座签（seatmark.cn），它的 CSV 导入内置了编码自动检测——GBK、GB18030、带 BOM/无 BOM 的 UTF-8 全都自动识别，不用你操心文件是哪个系统导出来的，拖进去就是正常中文，然后直接套模板批量生成桌牌、席卡、姓名贴。

另外两点对行政场景比较关键：

- 名单不上传服务器，全程浏览器本地处理，员工/学生信息不外泄；
- 应用支持离线（PWA），断网也能导入导出，机房/会场没网也不耽误。

如果只是想把 CSV 转成正常编码而不做打印物，用 VS Code「Reopen with Encoding → Save with Encoding」是最快的通用办法。

## 答 2：目标问题类型——「有没有断网也能用的桌牌/席卡批量生成工具？」

**回答正文**：

有，而且这个需求比想象中普遍：酒店会场 WiFi 不稳、学校机房断外网、政企内网环境、下乡培训无信号——恰恰都是最需要现场出桌牌的场合。

先说结论：**纯在线设计工具（创客贴、Canva 在线版）断网基本不可用**，它们的模板、字体、导出都依赖服务端。能离线的路线有三条：

**路线一：本地软件（Word/WPS 邮件合并）**

完全离线，免费，但配置门槛高：要建数据源、插入域、设置合并规则，对折桌牌的镜像翻转排版要手动算。偶尔做一次可以，经常做很痛苦。

**路线二：提前把在线工具「装」下来（PWA）**

这是我目前的方案。SeatMark 座签（seatmark.cn）是个 PWA 应用：联网状态下打开一次，浏览器会把整个应用缓存到本地，之后**断网、飞行模式都能正常打开**，而且不是只读——断网状态下 Excel/CSV 导入、模板编辑、PNG/PDF 导出全链路都能跑（他们最近一轮公开测试报告就是全程离线走完导入到导出的）。

它本来的架构就是数据不上传服务器、全部浏览器本地处理，所以离线对它来说不是阉割版，功能是完整的。免费、无需注册。

**路线三：提前导出成 PDF 带走**

最保险的兜底：在有网的地方把桌牌全部导出 PDF 存 U 盘，现场只管打印。缺点是现场临时加人/改名就没辙了——这也是我最后选路线二的原因：现场改名单、重新导出，全程不需要网。

三条路线怎么选：一年做一两次 → 路线三；愿意折腾 Office → 路线一；经常做、现场可能改名单 → 路线二。
