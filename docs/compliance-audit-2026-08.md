# SeatMark 国内商用合规审计报告（2026-08）

审计范围：wookat/SeatMark 全仓库（app 前端、edge-functions、README/LICENSE/docs）与线上站点 www.seatmark.cn 对应代码。
审计依据：《个人信息保护法》《网络安全法》《数据安全法》《儿童个人信息网络保护规定》《广告法》《价格法》及 ICP/公安备案相关规定。

## 一、已在本次 PR 中修复的问题

### 1. 法务文本（/terms /privacy 全面重写）
- **用户协议**：新增协议订立主体（占位符【运营主体名称】）、未成年人使用提示、账号管理与注销条款、名单数据处理者义务提示（导入学生名单时用户是个人信息处理者）、免责条款合法化（不排除法定责任、不损害消费者法定权利）、法律适用与管辖（运营主体所在地法院）、15 个工作日答复承诺。
- **隐私政策**：按个保法结构重写——
  - 明确个人信息类别与用途：邮箱（账号）、HttpOnly 会话 Cookie（登录状态）、配额/分享统计（含 IP 单向哈希说明）、团队版预订信息、反馈内容；
  - 突出如实说明「名单与照片本地处理、不上传服务器」的核心承诺及边界（可选功能的网络请求逐项列明：在线字体 CDN、AI 设计代理、验证码邮件）；
  - Cookie 与 localStorage 专章说明；Google Analytics + 百度统计如实披露；
  - 数据存储与保护措施、最短保存期限、境内存储（不出境）声明、安全事件告知义务；
  - 用户权利专章：查询/复制、更正、删除与注销、撤回同意、要求解释，15 个工作日响应；
  - 未成年人保护专章：引用个保法第 28 条（不满 14 周岁个人信息为敏感个人信息）与《儿童个人信息网络保护规定》，强调本地化架构在考务场景（学生名单）下的合规优势，并提示名单管理者的监护人同意义务。

### 2. 账号注销功能（支撑「删除/注销」用户权利）
- 新增 `POST /api/account/delete`：删除 user/云端模板/分享码/当日计数键并清除会话 Cookie；
- 账号页新增「注销账号」按钮（二次确认，说明删除范围）。

### 3. 备案展示位（组件化）
- 新增 `app/src/data/site.ts` 集中维护：运营主体名称、ICP 备案号（现值：湘ICP备2026009844号）、公安备案号（留空自动隐藏，办理后一改即全站生效）；
- 新增 `BeianInfo.vue` 组件：ICP 链接至 beian.miit.gov.cn，公安备案链接至 beian.mps.gov.cn 查询页（含盾形 SVG 图标）；页脚接入。

### 4. 广告法与文案整改
- 「全部 33 款内置模板」（定价页/README/教程/架构注释）与实际 61 款不符（虚假数据风险）→ 定价页改为动态取 `defaultTemplates.length`，文档改为 61；
- 「入园季萌趣首选」→「适合幼儿园入园季使用」（删除「首选」）；
- 「最通用的考场座位标签模板 / 是最通用的选择」→「通用性强 / 适用场景广泛」；
- 竞品对比文「四个方案中唯一内置此能力」→「本次实测的其他三个方案未内置此能力」（限定测评范围，避免绝对化）；
- 免费版「¥0 / 永久」→「¥0 /月」（避免「永久」承诺风险）；
- 定价页无「原价划线」虚构原价问题（专业版为「即将推出」、团队版明码标价 ¥99/月，合规）；
- 全站未发现「第一/顶级/国家级/99% 满意」等其余违规用语（教程中的「最省纸/最稳妥」等为操作方法描述，非产品宣传用语，风险低，保留）。

### 5. 安全整改
- **[高危] 硬编码企业微信 webhook key**（edge-functions/api/feedback.js 中的 `qyapi.weixin.qq.com/...key=f987...` 兜底值）→ 已删除，只读环境变量 `FEEDBACK_WEBHOOK`；**该 key 已泄露进 git 历史，请务必在企业微信后台重置该机器人 webhook**；
- 反馈接口新增同 IP 每日 10 次限频（IP 经 SHA-256 单向哈希后仅作计数），补齐表单防滥用；
- /account 与 /admin 页已确认输出 `noindex, nofollow`（此前已具备，无需修改）；
- AUTH_SECRET 仅有开发兜底值 `seatmark-dev-secret-do-not-use-in-prod`，生产需确认已在 EdgeOne 控制台配置（见待办）。

### 6. 本地化整改
- 页脚「All rights reserved.」→「版权所有」；
- edge-functions 全部英文错误提示中文化（Method Not Allowed / Invalid JSON body / Upstream request failed 等 → 中文）；
- 反馈弹窗的 emoji 图标（💡🐛💬）→ 内联 SVG（符合「UI 不用 emoji 图标」规范）；
- 验证码邮件模板此前已是中文，无需修改；
- 各页英文小字眉（Pricing / Templates / Terms of Service 等）为装饰性设计元素、正文均为中文，予以保留。

### 7. 知识产权核查结论（未发现侵权，无需代码修改）
- 在线字体许可核查：思源黑体/思源宋体（SIL OFL）、霞鹜文楷（SIL OFL）、马善政楷书 Ma Shan Zheng / 志莽行书 Zhi Mang Xing / 龙藏手书 Long Cang（Google Fonts，SIL OFL）、Inter/Roboto/Open Sans 等西文字体（OFL/Apache 2.0）均可免费商用；站酷小薇/站酷庆科黄油体为站酷官方发布的免费商用字体。fonts.ts 顶部已注明许可说明；

## 三、遗留低风险项（可暂不处理）
- 教程文章中的「最省事/最稳妥/最保险」等表述为操作建议而非广告宣传，广告法风险低；如需绝对稳妥可后续统一软化；
- 页面英文小字眉（Pricing/Guides 等）为视觉装饰，正文全中文，不影响合规；
- Google Analytics 为境外统计服务，当前仅收集匿名访问数据；如未来对数据出境要求收紧，可考虑移除 GA 仅保留百度统计。
