## 二、本轮发现并修复的问题

### P2-a　导出 toast 遮挡预览区工具栏（已修复）

- **现象**：toast 容器锚定右上（`top-30 / lg:top-16`），在 768/1280 下「PNG 图片已生成」「图片版 PDF 已生成」等导出提示恰好压在预览区吸顶工具栏的导出按钮（打印 / 图片版 PDF / 图片 PNG）上，导出完成后想立即再导出必须先等 toast 消失或手动关闭。
- **修复**：toast 改为右下角堆叠（`bottom-20 right-3`，`flex-col-reverse` 新消息靠下），下方让开右下角反馈浮动按钮（`bottom-5` + 48px）。
- **验证**：390/768/1280 三视口真实触发 PNG 导出成功 toast，均不再遮挡工具栏，也不与反馈按钮重叠。

### P2-b　弹窗层级与焦点管理（已修复）

走查对象：导出选择框、PNG 参数区、单张覆写、QuotaLimitDialog、打印校准、双面引导、提示说明（均基于 ModalDialog），以及反馈面板（FeedbackButton 自有实现）。

| 检查项 | 走查结果 | 处理 |
|---|---|---|
| Esc 关闭 | ModalDialog 支持；但**每个实例都监听 window，叠层时一次 Esc 会同时关掉所有层**；反馈面板不支持 Esc | ModalDialog 增加模块级打开栈，Esc 只关最顶层；反馈面板补充 Esc 关闭 |
| 焦点困陷 | 无：打开弹窗后 Tab 会跑到底层页面 | ModalDialog 增加 Tab/Shift+Tab 循环困陷，打开时聚焦面板，关闭后焦点归还触发元素 |
| ARIA 语义 | 缺 `role="dialog"` / `aria-modal` | 已补充（含 `aria-label` 取弹窗标题） |
| 连续开关残留遮罩 | 连续快速开关 5 次导出选择框，无残留 `inset-0` 遮罩（实测 0 个） | 无需处理 |
| 叠层遮挡 | 导出选择框 → 配额用尽时先关自身再开 QuotaLimitDialog（既有逻辑正确）；LoadingOverlay z-80 > ModalDialog z-60 > toast z-70 分层合理 | 无需处理 |

自动化验证（1280，导出选择框）：打开后焦点在弹窗内 ✔；连按 25 次 Tab 焦点始终困陷在弹窗内 ✔；Esc 关闭 ✔；关闭后焦点归还「图片 PNG」按钮 ✔；快速开关无残留遮罩 ✔。

### P2-c　/studio 超长名单（600 行）预览滚动与性能（仅评估，未改代码）

用 600 行 4 列 xlsx 实测（1280 视口）：

| 指标 | 实测 | 结论 |
|---|---|---|
| 导入 600 行到预览就绪 | 0.55 s | 优 |
| 翻页（下一页，双 rAF 到帧提交） | 83–129 ms（均值约 108 ms） | 可接受，无可感卡顿 |
| 预览容器滚动步进 | 26–46 ms | 流畅 |

原因：预览区只挂载当前一页标签（`workspace.currentPageRows`），数据表小预览仅取前 5 行，因此行数增长不放大 DOM 规模。**无明显卡顿，不做懒渲染改造**；若后续引入「整卷连续滚动预览」再评估虚拟滚动。
