## 1. 逐产品上手记录与技术反推

### 1.1 Avery Design & Print Online（本次最完整、最值得对标的对象）

流程（Avery 5395 姓名牌，2 1/3" × 3 3/8"，8 枚/页）：
Choose Template → Choose Design（约 1,455 款设计）→ Customize → Preview & Print，四步固定导航，永远知道自己在第几步。

名单导入（Import Data / Mail Merge）：
- 支持 `.xls/.xlsx/.csv`，限制 <3,000 行、<20 列、<600KB；
- 上传后可视化勾选行/列 → 「字段排布」面板里双击/拖拽字段、可在字段间插入文本/逗号/空格 → 一次合并生成全部标签；
- 合并后提供 Edit All / Edit One 两种编辑模式 + 多页 Navigator；中文数据（张伟/20260101/01…）全程正常。

导出/打印：
- 「Get PDF to Print」生成 PDF 到新标签页；打印弹窗内置三条打印须知（Actual Size/100%、介质选 Labels/Cardstock、先用普通纸试印）。
- 技术反推：预览区为 SVG 渲染；最终 PDF 为**服务端生成**（URL 指向 anonymous.print.avery.com；PDF Producer 为 BFO 商业 PDF 库；内嵌 Arimo/NotoSansSC/JP/TC 字体子集），2 页仅 343KB。
- 编辑器工具链完整：Undo/Redo/Copy/Paste/Align/Arrange/QR 与条码/序列号/曲线文字/透明度/行距。

证据：ss_0c42709f / ss_ad7edb7d / ss_86f7e2fe / ss_cac5bc59 / ss_32c378d1 / ss_c36012ae / ss_daaf163c / ss_8eb52451 / ss_f7ad09cf / ss_f981414c / ss_3388e242 / ss_3112cdda / ss_d6aaa74f。

**可借鉴**：① 字段排布 UI（字段间可插入文字/分隔符）；② 打印须知内嵌在导出动作里而不是教程页；③ Edit One（单张覆写）能力；④ 四步固定导航。
**我们已更优**：数据不出浏览器（Avery 名单上传到服务器）；毫米级自由排版与 16 种不干胶纸型；Avery 无中文界面、字体选择少。

### 1.2 Canva 可画（canva.cn）

- 免登录可浏览「会议桌牌」类目约 193 款模板，模板质感（真实设计感、图片背景、字体搭配）明显强于工具型产品；
- 进入编辑必须登录；临时邮箱注册在提交验证码后被安全风控拒绝（ss_2b402ce5）；英文站遭 Cloudflare 人机验证（ss_dfd5bd71/ss_02018c67）。编辑器体验未能实测，不做臆断评分。
- 公开资料与模板列表页 DevTools 观察：列表页为 SSR + 图片懒加载；Canva 的定位是通用云设计工具，**没有**「Excel 名单 → 批量套打 → 毫米级拼版」的考场场景闭环，批量功能（Bulk Create）在国际版付费档。
- 证据：ss_e7cbe65f / ss_ad93204b / ss_2b402ce5 / ss_dfd5bd71 / ss_02018c67。

### 1.3 稿定设计

- 目标页直接 HTTP 405「异常访问」拦截（ss_bcf8b5ab）；经中国 VPS SOCKS5 代理复测仍 405，属 UA/风控级拦截而非地域封锁。无法实测，仅记录。

### 1.4 创客贴

- 通用搜「桌牌」5,000 结果（掺大量海报/PPT，噪音大，ss_131a65af）；专类「桌牌台签」仅 23 款（ss_82384dfb），画布 198×196mm（V 型对折台卡），少量标注「免费」，多数付费/会员。
- 点模板进编辑 → 强制登录弹窗：仅微信扫码 + 手机号注册，无邮箱通道（ss_9e342d6c）；浏览途中还触发过腾讯滑块验证码（ss_bf8483dc 等）。编辑器与批量导入未能实测。
- 技术反推（列表页）：Nuxt SSR，缩略图为 CDN 静态图（pub-cdn-oss.chuangkit.com），大量内联 SVG 图标；公开帮助文档显示其批量功能面向「智能设计/批量套版」，主要在会员档。
- 判断：创客贴桌牌模板质感好但**专类供给少（23 款 < 我们 153 款）**、登录墙+付费墙重、无考场名单批量闭环。

### 1.5 classtool.cn 座位表生成器（免登录，全流程可用）

- 流程：示例名单一键导入 50 人 → 「随机排座」三模式（男女混排/男女分开/完全随机，内置常用名性别识别）→ 拖拽换位、整排交换 → 导出 PNG（74.7KB，长图自动适配）；另支持导出 Excel、教师/学生双视角、10+ 皮肤、localStorage 持久化（刷新不丢）。
- 技术反推：纯前端 DOM 渲染 + html2canvas 类导出；数据本地存储不上传（与我们同承诺）。
- 定位差异：解决「谁坐哪」的**排座**问题，不做物理桌签/标签的毫米级打印；与我们 /seating 直接竞争，与 /studio 互补。
- 证据：ss_b35ff13a / ss_2ac7793f / ss_3752eaa0 / ss_5e3af46e。
- **可借鉴**：① 示例名单一键体验门槛极低；② 排座模式（性别混排）；③ 皮肤/视角切换。

### 1.6 易排座（fish78.com/class-grid）

- 网页只是落地页：产品为微信小程序 v2.2.5（uni-app + Vue），支持上千座位、拖拽换位、多排位模式、高清导出与分享，需微信扫码使用，无网页版可测（ss_b4866b3b）。
- 定位同 classtool：排位工具，非标签打印。移动端/微信生态触达是其优势，提示我们微信内分享/使用路径值得关注。

### 1.7 SeatMark（seatmark.cn，同一名单走同流程）

流程实测：
- 落地页即展示 A4 真实排版效果 + 「用演示数据先试试」入口（ss_c1af98ae）；
- /studio 四步（选模板 → 导入数据 → 字段映射 → 页面与版式）；上传 roster.xlsx 后即时按毫米渲染 A4 预览，裁切线/高亮缺失/打印校准/两种导出按钮齐备（ss_27ebc397）；
- 「超清图片 PDF」前端导出成功（jsPDF 4.2.1，纯本地，无任何名单网络上传——DevTools 网络面板确认，数据不出浏览器承诺属实）；
- 响应式实测 390/768/1280 三档 home/studio/templates 均无横向溢出（scrollWidth == clientWidth）。

实测发现的问题（详见第 4 节）：
- **字段自动映射错误**：Excel 明明有「座位号」列，自动映射却把「座位号 → 考号」，导致标签大字位置显示 20260101 而非 01，需要手动纠正（ss_27ebc397 可见）；
- **超清图片 PDF 体积失控**：10 枚标签 1 页导出 66.9MB（Avery 2 页矢量仅 343KB）；
- 无水印导出每日 1 次的配额提示出现在导出弹窗内，首次导出前无预告。

## 2. 技术实现对照（DevTools 反推）

| 维度 | Avery | Canva（列表页+公开资料） | 创客贴（列表页） | classtool | SeatMark |
|---|---|---|---|---|---|
| 编辑器渲染 | SVG | Canvas（公开资料） | 未测（列表 Nuxt SSR） | DOM | DOM + CSS mm 物理单位 |
| 导出管线 | **服务端** BFO 生成 PDF | 服务端导出 | 未测 | 前端 canvas→PNG | **前端** 浏览器打印(矢量) / jsPDF(图片) |
| 名单数据去向 | 上传服务器 | 上传服务器 | 上传服务器 | 本地 | **本地（实测确认无上传）** |
| 字体策略 | 服务端嵌 Noto 子集 | 云字体库 | 云字体 | 系统字体 | 开源字体 + 系统字体，打印时随浏览器嵌入 |
| 模板数据 | 服务端模板 | 专有 JSON | 服务端模板 | 无模板 | 开放 JSON（可导入/导出/分享链接） |
| 离线可用 | ❌ | ❌ | ❌ | 部分 | ✅ |

结论：SeatMark 的「前端矢量打印 + 本地数据」在隐私与离线上是独有优势；代价是图片 PDF 体积、字体嵌入依赖浏览器打印对话框，这两点需要工程优化（见 P1）。

## 4. 差距问题清单（P0/P1/P2，落到组件/文件级）

### P0（影响正确性/主流程）

1. **字段自动映射错误：存在同名列时未优先精确匹配**
   - 现象：roster.xlsx 含「姓名/考号/考场/座位号」四列，自动映射结果为「座位号→考号」，标签主字位错误显示考号（证据 ss_27ebc397）。
   - 改进：字段映射算法先做**列名精确匹配**（含全半角/空白归一化），精确命中后从候选池移除该列再做模糊匹配；映射结果与预览联动高亮，映射异常（一列被两个字段抢用/精确名列未被采用）时给出警告条。
   - 落点：`app/src` 内负责 Excel 解析与字段映射的 store/工具（Pinia store 中 mapping 逻辑，及「3 字段映射」面板组件）；补 Vitest 用例：精确同名列必须优先命中。

### P1（影响体验/口碑）

2. **超清图片 PDF 体积失控（1 页 66.9MB）**
   - 原因反推：整页 PNG 以无损/超高分辨率嵌入 jsPDF。
   - 改进：导出时按页数自适应 DPI（≤2 页 300dpi 足够）、PNG→JPEG(0.92) 或对纯文本页改用矢量打印路径引导；导出前显示预估体积。
   - 落点：图片 PDF 导出模块（jsPDF 调用处，`addImage` 的格式与压缩参数）。
3. **模板质感与 Canva/创客贴有代差**
   - 改进：为高频场景（会议桌牌/席卡）新增 10–20 款「设计感」模板：渐变/几何底纹（SVG 内联，不引图片资源保持离线）、更丰富的开源字体搭配；模板 JSON 增加装饰元素图层。
   - 落点：`app/src/data/defaultTemplates.ts` 增补 + `LabelCard` 支持装饰图层渲染（如尚未支持背景 SVG 图形）。
4. **字段排布灵活性不及 Avery**
   - 改进：字段映射支持「组合字段」——一个槽位绑定多列并可插入分隔文本（如 `第{考场}考场-{座位号}号`）。
   - 落点：字段映射数据结构与「3 字段映射」面板；`LabelCard` 取值逻辑改为模板串求值。

### P2（增强/差异化）

5. **排座功能补齐 classtool 关键能力**：随机排座（完全随机/男女混排）、整排拖拽交换、教师/学生双视角。落点：`/seating` 路由对应页面组件与其 store。
6. **导出配额预告**：在点击「超清图片 PDF」按钮前（tooltip 或按钮角标）展示今日剩余次数，而非点开弹窗才知道。落点：工坊工具栏导出按钮组件。
7. **Edit One（单张覆写）**：合并后允许对某一枚标签单独改字（Avery 同款能力），落点：预览区标签点击 → 覆写弹层，覆写数据存 store 的 per-row override。
8. **微信生态触达**（对标易排座）：至少提供「复制分享链接 + 微信内打开引导页」，站点已具备分享链接基础。

## 8. 增量章节 · 第三轮竞品体验跟进（2026-08，配合智能适配/演示数据/组合字段上线后复查）

### 8.2 稻壳（docer.com）观察

- 搜索垂类切换（所有/PPT模板/应用文书/表格/图片素材/PDF）+ 风格/用途/行业/颜色/比例/价格多维筛选，信息架构完整；但「席卡」在 PPT 垂类 0 结果（`r3/docer-xika.png`），品类词覆盖弱于我们（我们 215 款且有二级分类）。
- **值得学：空结果页不是死胡同**——0 结果时给「热门下载/最受欢迎的设计师」等兜底推荐区。我们 `/templates` 搜索空结果目前只有提示文案，可补「热门模板」兜底（P2，落点 TemplatesView 空状态）。
- 席卡/桌牌打印在稻壳生态里本质是「Word 模板 + WPS 客户端邮件合并」流程：网页端无法完成闭环，门槛远高于我们的浏览器内三步流程——这正是我们落地页可强调的对比点。

### 8.3 Canva 可画（canva.cn）观察

- 「桌牌模板」有独立类目落地页（`/templates/?query=桌牌`，标称 10,000 模板，截图 `r3/canva-zhuopai.png`）：大标题 + 一句话引导 + 预填关键词的搜索框 + 「所有筛选条件」入口，SEO 与转化兼顾。我们的 `/templates` 已有分类 chips，可考虑为高频品类词（桌牌/席卡/考场座签）生成带预填筛选的着陆锚点（P2）。
- **值得学：模板详情弹层的「设计细节」区**（`r3/canva-template-detail.png`）：色板色条、字体清单、物理尺寸（210×100 毫米）结构化展示，并有「更多相似内容」推荐横排。我们模板详情页可补「本模板用色/字号/尺寸」结构化块与相似模板推荐（部分已有，色板/字体维度缺失）（P2，落点 TemplateDetailView）。
- 双页/双面模板以「第 2/2 页」角标 + 缩略图切换呈现，正反面关系一目了然——对照我们「对折双联（镜像）」目前只是复选框 + 问号说明，可视化程度不及（记录，交互层面不动手）。
- 模板卡片命名规范「颜色+风格+场景+品类」（如「绿色法式复古风婚礼活动菜单双页桌牌会议牌」），检索友好；我们模板名偏短（「标准考场版」），搜索场景词覆盖可在 description/tags 层补足（已有拼音首字母搜索，属增强项）。
- 对照我们新上的智能适配/演示数据/组合字段：Canva/稻壳均无「模板×纸型适配度评分」与「一键演示数据」同类能力，属我们的差异化点，保持并在教程中显性宣传。
