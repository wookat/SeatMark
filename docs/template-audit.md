> 审查方式：起本地 dev server，用统一渲染入口逐款渲染全部 61 款内置模板，每款截取 **样例数据** 与 **极端数据** 两张截图（共 122 张）做视觉识别检查。
>
> 极端数据集：长姓名「欧阳娜娜贝尔」、18 位准考证号「202611430102030405」、17 位学号、长考场名「第十九考场（东三楼）」、各文本字段追加「加长测试文本」后缀、座位号「128」。
>
> 检查维度：字段对齐 / 字号层级 / 行距 / 留白、文本溢出或过挤、颜色对比度与黑白打印友好度、圆角与边框裁切安全距、sampleData 是否得体。

## 一、系统性问题与通用规则（高频问题沉淀）

### 问题 A：长文本溢出 → 省略号截断（系统性，影响几乎所有模板）

修复前，所有文本字段为**固定字号**：长姓名渲染为「欧阳娜娜…」、18 位准考证号被截断（`standard`、`examNo`、`deskName`、`large`、`fullPage` 等大量模板的极端数据截图均复现）。座签是物理打印品，出现省略号等于废纸。

**通用规则（已实现）**：在唯一渲染源 `LabelCard.vue` 中新增 `v-autofit` 指令——
- 以模板字号为**最大字号**，内容溢出时二分收缩至恰好放下；
- 最小字号 = 基准字号 × 0.5（且不低于 5pt），保证层级关系不因收缩而倒置；
- 在线字体加载完成（`document.fonts` loadingdone）后自动重排，避免字体切换后再溢出；
- 预览 / 缩略图 / 设计器 / 导出 / 打印全链路生效（同一渲染源）。

修复后复测：全部 61 款极端数据截图无省略号、无字符裁切；短内容渲染与修复前逐像素一致（字号不变）。

### 问题 B：V 型折叠桌牌上半区空白（功能缺陷）

`vTent` 沿中线对折成 V 型立于桌面，但修复前上半区完全空白——对折后背面无字，只有单面可读，与「V 型双面」定位不符。

**通用规则（已实现）**：字段模型新增 `rotate`（绕中心旋转）与 `mirrorOf`（镜像另一字段数据、不参与 Excel 映射）。`vTent` 上半区新增旋转 180° 的镜像姓名/单位字段，对折后两面同向可读。

## 三、针对性补充模板（7 款，均有明确差异价值）

审查发现的品类空白与补充理由：

| 新模板 | 分类 | 差异价值（现有库缺口） |
| --- | --- | --- |
| examBag 试卷袋标签 | exam | 现有考试类全部面向「考生个人」，缺**考务物料**标签；科目大字 + 份数徽章 + 密封人/日期签字行 |
| examDoor 考场门贴 | exam | 缺「考场级」引导物料：A4 整页考场号特大字 + 准考证号区间 + 楼层指引 |
| tentBilingual 双语会议桌牌 | event | 现有桌牌均纯中文；中文特大字 + 西文衬线英文名 + 职务，覆盖涉外会议 |
| checkinZone 签到分区牌 | event | 缺签到台**分流**物料：分区字母特大字 + 姓氏区间说明，A4 横向整页 |
| shelfCategory 图书角分类牌 | teaching | bookLabel 是「单本书贴」，缺**书架分区**牌：分类色块 + 分类名 + 编号区间 |
| kidsBirthday 生日派对席卡 | kids | 幼教类全是「日常归属」标签，缺活动场景：暖粉席卡 + 年龄徽章 + 自定义祝福语 |
| clinicDoor 科室门牌 | life | 缺「房间级」门牌：房间号满高色块 + 科室名大字 + 负责人，医院/办公室通用 |

7 款均通过与内置模板相同的样例 + 极端数据双截图审查及 `layoutOverflow` 版面越界单测。
