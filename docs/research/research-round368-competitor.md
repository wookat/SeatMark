## 一、本轮相对第 367 轮的增量发现

### 1. 中文桌面小工具生态持续活跃，评论区直接暴露未满足需求（【直查】52pojie + gitee）

- 吾爱破解「桌牌/台签/桌签/批量打印工具」已迭代到 **v2.8（2026-08-25 更新）**，AI 二次开发自开源版：Excel/TXT 名单导入、可视化画布拖拽、双面镜像打印、自定义纸张/标签/行列/背景、方向键像素微调。评论区高频诉求两条：
  - 「**有没有配置保存功能**，就不用每次打开都重新设置参数，配置文件给到其他人也可以快速打印」→ 参数/配置持久化与可携带是真实痛点（SeatMark 模板 hash 分享正好命中「给其他人复用」这一半）。
  - 「姓名长度不同的时候 设置水平缩放把短姓名也缩小了」「**能实现根据字数自动缩放，宽高比调整就方便了**」→ 按文本长度等比自适应缩放是中文用户明确点名要的能力。
- **代码核实**：SeatMark 已具备 `v-autofit`（LabelCard.vue:90，超出字段框按比例缩小字号至下限）+ localStorage 持久化 + 模板 hash 分享——即 52pojie 评论区点名的两个缺口 **SeatMark 均已覆盖**，应作为对国产桌面工具的显性卖点写进对比页/官网叙事。
- SeatPrint（gitee.com/zhux3/seat-print）开源桌面程序：双面批量打印、台签规格自定义、镜像/标签模式、F7 高级设置——同赛道仍存在活跃开源参照物。

### 2. 「扫码查座」海外同构产品继续出现，且加了「查座数据分析」（【直查】venued.app / seatyourself.io）

- **venued.app**：宾客名单 → 数字座位表 + QR 码，宾客扫码输姓名秒查桌位/座位；改动实时生效；Excel/Google Sheets 导入；定价分档；**独有卖点：查座数据分析**（total scans、popular tables、event notes）。免费档 + 付费档（2 events/1000 guests/QR styling/去广告等权益分层）。
- **seatyourself.io**：同构——扫码查座、无 App、手机端临场改座、Copy Link/QR 分享。
- 与 R366 判断一致：全部为名单上云架构，与零上传铁律冲突；但「扫码自查」需求在英文市场也被反复验证（WedBuild 文章亦提「QR code 查座 + morning-of 改动实时触达」）。合规变体（hash 编码名单的自查只读页）价值进一步上升。

### 3. 排座赛道新进入者仍在涌现（【直查】Product Hunt 快照）

- **SeatingSorted**（PH 2026-08，未上 featured）：「Let AI solve your seating」——画房间→设规则（谁不能同桌/必须同桌）→自动生成排座并预标冲突；**一次性买断、非订阅**——定价叙事上又添一位「不买订阅」玩家。
- **EasySeatingChart**（PH 2026-09-01）：免费、浏览器、免注册、粘贴名单+拖拽+keep-apart 规则——SCG 模式的直接复刻，说明「免费无账号排座」已被视为可复制的最小形态。
- 含义：免费免注册排座工具供给增加 → SeatMark 的「免费+免登录」不再是差异项，差异项 = 毫米打印精度、考务/会议中文场景、牌卡物料（不只是排座图）、隐私零上传。

### 4. SeatLogic 定价结构更新（【直查】定价区）

- 新增 Monthly/Yearly 切换：Essential $33.33/月（按年付 $399.99）、Professional $83.33/月（按年付 $999.99）、Free ≤100 宾客。PeerPush 收录显示「Freemium from $39.99」【二手】，应为按月付价。

### 5. PerfectTablePlan 专业版的「条码签到」值得记录（【直查】purchase/compare 页）

- 定价不变：$29.95 / $74.95 / $299.95 一次性买断（宣称 65,000+ 份售出）。
- Professional 独有项含「**Add barcoded IDs to stationery**」+「**Check-in guests with a USB barcode scanner**」——把每张席卡上的条码做成**现场签到核销**入口，与 G3（每张卡变量二维码/条码）同族但更靠近「签到/核验」场景，强化该机会点的证据链。

### 6. TopTablePlanner 定价复核（【直查】purchase 页）

- Personal £10 / Personal Plus £15 / Professional £40；个人档同时仅可存 5 个方案；6 或 12 个月使用权、**不自动续费**；商业用途必须 Professional；慈善机构可邮件申请折扣。功能面（拖拽/RSVP/餐食/席位卡/escort card/PDF）与前几轮一致。

### 7. 创客贴会员体系改版（【直查】price/vip 页）

- 现行版本：**免费版 / 基础版 / 高级版 / 专业版（单人）+ 团队版（高级/专业/至尊）**，权益核心是 AI 积分制（单人版月赠 600/1500/3800 积分），存储 3GB→1TB 分级。
- 「**批量套版设计**」仍明文列在内容编辑能力中（团队版含「批量设计」表述）；**未验证是否逐行数据合并**（不注册不登录，维持监控项）。
- 值得注意的法务信号：页面明示侵权赔偿「单个模版/元素 5000–10000 元、单款字体 10000–30000 元」——模板站把「版权成本」写进定价页，反衬 SeatMark 自带模板库的零版权风险叙事可强化。

### 8. SeatingChartGenerator 场景页继续膨胀（【亲测】首页）

- 首页生成器入口已远超 10 个：Ballroom Wedding / Company Gala / Birthday Party / Charity Banquet / Garden Wedding / Grade 5 Classroom / Classroom Desk / Round Table / Long Table / Head Table / U-Shape 等密集铺列——「一场景一工具页」SEO 密度进一步拉大，与 SeatMark TopicLanding+指南密度差距继续存在（G11）。

### 9. WPS 官方社区自证「三条路都有明显短板」（【直查】forum.wps.cn 官方帖）

- WPS 社区 2026-03 帖《三种制作会议座签的方法》给出官方口径对比：
  - WPS 文字（邮件合并）：设计自由度高，但「**数据修改能力弱，人员名单批量调整需重新走邮件合并流程**」「内置座签模板较少，从零开始要自行调页边距/文本框」。
  - WPS 表格：数据管理最强，但「**视觉设计能力弱……竖排文字、图文混排步骤烦琐**」。
  - WPS 演示：上手最简单，但「**没有批量数据导入功能，100 份以上需逐个修改**」。
- 即官方承认三条默认路径各自残缺——SeatMark「上传即排版、改名单即改输出」的叙事正中缺口。另有多篇 2026 年新教程仍在手把手教「量塑料底座尺寸→插矩形→手动旋转 180° 做正反面」，印证默认方案的高门槛与翻车率未变【二手】。

### 10. 中文婚礼排座的本质是「关系约束求解」，深度内容仍在更新（【二手】hunzha 2026-07 长文）

- 婚庆行业文（2026-07）把婚宴排座归纳为人情关系网：主桌排位（辈分/男左女右/双方家庭平衡）、离异父母与再婚家庭的多桌贵宾策略、「认识≠聊得来」的分桌原则（同学/同事/兴趣圈分桌）、长辈座位=面子信号。
- 对 SeatMark 的启示：中文婚礼排座的核心不是「把名单填进桌」，而是**关系分组 + 排斥/聚合规则 + 主桌/贵宾桌的层级表达**。SeatMark 宴会视图已有「不同桌」软排斥（代码核实：手动拖入同桌仅提醒不阻止），但「同组聚合」「主桌/贵宾层级」「按关系圈自动分桌」均无对应概念。

### 11. 「单一数据源」是 spreadsheet 教程派与工具派共同的痛点答案（【二手】layer7designs / wedbuild）

- layer7designs（2026-08）：教人把宾客名单/RSVP/餐食/座位表放进**一张表一个公式**，理由是「名单在一处、座位表在另一处，第二处更新总会被漏掉」——数据不同步是 spreadsheet 路径的原生病。
- WedBuild（2026-08）：强调名单变更（临时退出/突然加一/婚前一周分手）时拖拽改座 vs 午夜重画整张图的对比。
- → 再次印证「**改名单的成本**」是工具价值的核心度量；SeatMark 的「增量改名单、改完即导出」链路是主叙事方向。

## 二、用户真实讨论 → 未满足需求（标注证据）

1. **中文桌面工具用户直接点名「配置保存」和「按字数自动缩放」**：52pojie v2.8 评论区【直查】——两条诉求 SeatMark 已覆盖（持久化+模板 hash、v-autofit），属「对手用户教育出来的现成卖点」。
2. **WPS 官方承认三条默认路径各自残缺**：邮件合并改名单要重走流程、表格设计感弱、演示无批量导入【直查】——「改名单即改输出」是官方方案永远给不了的。
3. **婚宴排座=关系约束+面子层级**：hunzha 长文【二手】——主桌排位、离异父母、关系圈分桌是中文婚礼独有深度；对应「关系分组/主桌层级/同桌聚合」类功能空白。
4. **「数据不同步」是 spreadsheet 路径原生病**：layer7designs「第二处更新总会被漏掉」、WedBuild「午夜重画整张图」【二手×2】——单一数据源+改完即导出继续作为主叙事。
5. **扫码查座需求在英文市场同样被反复验证**：venued（含查座数据分析）、seatyourself、WedBuild QR【直查+二手】——需求真实，实现架构与铁律冲突，合规变体（hash 名单自查页）价值上升。
6. **席卡/签到一体化**：PTP 专业版条码签到、中文核验场景（准考证照片核验）【直查+二手】——每张卡变量码的用途从「装饰」升级为「核验/签到/查座入口」。
7. **模板版权成本显性化**：创客贴定价页明码标注侵权赔偿额【直查】——自建模板库的零版权风险是可讲卖点。
8. **免费无账号排座已成可复制最小形态**：EasySeatingChart、SeatingSorted、SCG 系【直查】——SeatMark 免费叙事必须叠加「中文场景+打印精度+隐私+牌卡物料」组合拳。

## 四、机会点（按「投入小 / 差异大 / 不违反铁律」排序；在 R367 基础上更新）

1. **每张卡二维码/条码字段**（G3，本轮升至首位）：PTP 条码签到、venued QR 查座、中文核验场景三向证据；仓库 qrcode.ts 现成，新增 `qr` FieldType 绑名单列即可命中核验/签到/自查。
2. **排座 hash 快照分享**（G7）：wedgenerator 已实证零后端可行；seatyourself Copy Link 说明「分享排座」是通用诉求；回应 spreadsheet 版本混乱。
3. **「不同桌」硬约束 + 同组聚合 + 主桌层级**（G1/G26）：宴会软排斥基础上加「必须/尽量」两档 + 「同组优先同桌」聚合 + 主桌标记；hunzha 证明中文婚礼关系复杂度远超西方 keep-apart。
4. **校对防错与可读性护栏**（G23）：导出前最小字号/对比度/疑似错字提醒 + 打样一页提示；v-autofit 下限以下时给出警示。
5. **先试打一页引导**（G15，沿用）。
