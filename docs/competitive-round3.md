## 一、本轮实际上手记录（5 家可访问 + 4 家被拦截）

### 1.1 抽奖吧·姓名卡片批量生成器（choujiangba.com/tools/name-card）——新玩家，历史研究未覆盖

- **上手过程**：免登录进入，预填 107 个示例姓名，点「生成并下载全部 (ZIP)」，数秒即得 `name_cards.zip`（107 张 PNG，按姓名命名，800×500px）。全程零门槛。
- **能力**：14 种卡片样式 + 15 组配色预设；像素尺寸/边距/行高/字距/字体（仅 6 款系统字体）可调；实时预览。
- **短板**：①仅 PNG 逐张导出，**无 A4 拼版、无对折线/裁切线、无 mm 物理尺寸**（纯 px）；②名单只能粘贴，无 Excel 导入、无多字段（职务/桌号）；③无照片；④生成在前端完成但站点主业是年会抽奖大屏（引流工具）。
- **定位判断**：对 SeatMark 的「打印级」场景无直接威胁，但**免登录+秒出 ZIP 的顺滑度**和「按姓名命名 PNG」与我们 eink/批量命名能力同路线，且它做了 SEO 落地页（标题堆「姓名卡片批量生成器|席卡制作工具|桌牌在线生成」），已在百度/Google「桌牌在线生成」词面与我们抢量。
- 证据：`choujiangba-name-card-home.png`、`choujiangba-zip-download.png`（实测下载的 zip：107 个 PNG 文件按姓名命名）。

### 1.2 数年网路·姓名卡牌批量生成打印工具（shuyear.com/a/seatplate_17.html）——新收录的长尾小工具

- **上手过程**：免登录，粘贴名单（空格/换行分隔），页面即时渲染上下镜像的对折卡牌，点「开始打印」走浏览器打印。
- **能力**：宽/高按 **mm** 设置、字号 pt、加粗、自动兼容长短姓名、**正反两面镜像（对折后双面可读）**、留裁剪边线。
- **短板**：单字段、无模板/设计感、无 Excel、无照片、依赖浏览器打印（无 PDF 导出、无校准）；个人站（湘ICP），UI 简陋。
- **定位判断**：验证「镜像对折 + 裁切线」是行政/考务真实刚需的又一佐证；功能是 SeatMark 子集，无威胁。它靠单页长尾 SEO（「姓名卡牌批量生成打印在线工具」）被百度收录获客。
- 证据：`shuyear-name-card-tool.png`。

### 1.3 placecard.us（中文站 /zh）——历史已知海外新玩家，本轮首次实机上手，**变化最大、最值得警惕**

- **上手过程**：免登录进入 /zh/place-card-maker，四步向导（选模板 → 宾客名单 → 自定义 → 预览导出）预填 5 条示例数据即可走通；点「导出 PDF」弹出**双轨弹窗：带全页水印的免费预览 PDF vs「2 积分」无水印高清导出（需登录）**。
- **本轮新确认的能力**（相比 overseas-market-research.md 记录时又有扩张）：
  - **完整中文本地化**（/zh 全站，含博客/指南/帮助中心/价格页），已明确面向中文用户；
  - Excel/CSV/Google Sheets 导入 + 字段映射（guestName/tableNo/seatNo/meals），宣传「Excel 和 CSV 在浏览器本地读取」——**本地隐私叙事与我们几乎逐字相同**；
  - 纸型布局：US Letter/A4/Avery 5302/6-up/折叠桌卡 + 裁切线样式可选（角标等）；
  - 生态获客件：**Chrome 扩展、Google Sheets Add-on、Amazon Listing、GitHub 社区、YouTube/Pinterest** 全渠道铺开；
  - 变现：一次性套餐（入门 $12.9/100 宾客/30 天 → 专业 $39/500 宾客/1 年 → 商用终身 $99），无订阅、水印预览免费。
- **相对短板**：模板以欧美婚礼风为主（≈100+），无中国考务/校园场景、无照片匹配、无打印校准向导、无 eink、无 PWA 离线；清晰导出必须登录+付积分（我们免登录带水印可打）。
- **定位判断**：它是「SeatMark 模式」在海外的镜像，且已反向做中文站进入中文词面。**我们的 SEO 词面（座位卡在线制作/Excel 批量席卡）将与其 /zh 站短兵相接**。
- 证据：`placecardus-zh-landing.png`、`placecardus-templates.png`、`placecardus-export-preview.png`、`placecardus-watermark-credits-modal.png`。

### 1.4 创客贴（chuangkit.com）——复查，有一处需登录截止的变化确认

- **上手过程**：进站触发腾讯滑块验证（可过）；「桌牌台签」品类页正常（198×196mm 对折桌牌，模板详情页标注可导出 jpg/png/pdf）；点「开始编辑」即弹**微信扫码登录墙**，未登录无法进入编辑器。
- **本轮确认**：①编辑器门槛 = 登录墙（与 Avery 同路线）；②站内搜索页 /search 直接 404，模板检索路径退化，只能靠外部搜索引擎进入模板详情页；③桌牌品类仍无名单批量、无拼版概念；印刷店一站式下单仍是其独有闭环。
- 证据：`chuangkit-zhuopai-template.png`、`chuangkit-login-wall.png`。

### 1.5 Pixeva Place Card Generator（pixeva.co/free-tools/place-cards）——新玩家（海外，活动照片 SaaS 的引流工具）

- **上手过程**：免登录，预填 6 位宾客（姓名/桌号/餐食），前/背面 3D 预览，一键「Print & Save PDF (A4 Sheet Layout)」，支持 Foldable Tent/Flat Card、5 套奢华主题、Bulk Import。
- **独特玩法**：背面自动嵌入**照片上传 QR 码**（链到其共享相册产品）——把免费桌卡工具做成了主产品（AI 活动照片识别 SaaS）的获客钩子，还配了 /compare/pixeva-vs-xxx 对比页矩阵。
- **短板**：无 Excel 映射（仅简单批量粘贴）、无毫米/纸型体系、模板少、英文。
- **定位判断**：功能无威胁；**「免费工具做引流钩子 + QR 增值联动 + /vs 对比页」的获客打法**值得直接复用。
- 证据：`pixeva-place-card-gen.png`。

## 四、竞品获客渠道反推 + SeatMark 可复用的 3 个动作

**渠道反推**：
- 抽奖吧：百度/Google 长尾词落地页（「姓名卡片批量生成器｜席卡制作工具｜桌牌在线生成」标题三连）+ 主站工具矩阵互链（节目单/倒计时/抽奖券），工具间互相导流。
- 数年网路：个人站单页长尾 SEO + 友链堆权重。
- placecard.us：内容矩阵（博客/指南/帮助中心多语言）+ Chrome Web Store / Google Workspace Marketplace / Amazon 三个「应用商店」分发位 + YouTube/Pinterest 视觉搜索 + GitHub 开源社区人设。
- 创客贴：品牌词 + 模板详情页 SEO（每个模板一个 URL 被搜索引擎收录，本轮我们正是从 Google 直达其模板页）+ 印刷店闭环留存。
- Pixeva：免费工具作主产品钩子 + /compare 竞品对比页 + ProductHunt。

**可复用的 3 个具体动作**（均不改产品代码，1–2 轮可落地）：
1. **每模板一页的可收录详情页**（学创客贴）：为 222+ 模板生成静态详情页（模板名+尺寸+场景关键词+「立即使用」深链），让长尾模板词自然收录——我们已有 SSG 能力与模板元数据，纯增页不动产品。
2. **/vs 对比页矩阵**（学 Pixeva/placecard.us）：先出 4 页（vs WPS 邮件合并、vs 创客贴、vs Canva、vs placecard.us），素材直接取本文档第二节对照表与截图，承接「XX 和 XX 哪个好」对比词。
3. **工具矩阵互链钩子**（学抽奖吧）：把「座位表生成」「打印校准页」「生僻字检测」等已有子能力拆成独立 SEO 落地页（各自命中「座位表在线生成」「打印偏移校准」等词），页内互链回主编辑器，形成站内工具群。

## 五、结论

1. **最大威胁变化**：placecard.us 已完成中文化并复制我们的本地隐私+Excel 批量叙事，是首个「同模式、双语、生态分发齐全」的镜像对手；其套餐价（$12.9 一次性起）与我们 ¥29 专业版直接可比。
2. **新玩家性质**：国内新出现的免费小工具（抽奖吧、数年网路）功能均为我们子集，但在「零门槛秒出图」体验和长尾词占位上对我们的获客面构成侵蚀；应对靠 SEO 落地页与「快速模式」，不靠功能军备。
3. **护城河仍成立**：打印校准（≤0.35mm）、17 款纸型双向适配、照片匹配、eink、座位表联动在本轮所有可访问竞品中依然无一具备。
4. **本轮建议立即执行**（P0，均 1–2 轮内）：G1 长尾词落地页、G2 /vs 对比页矩阵；随后 G4 快速模式、G5 PNG 字段命名。
