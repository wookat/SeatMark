## 篇 1｜回答向：「有什么批量制作桌牌/席卡的免费工具？」

适配问题：批量做会议桌牌用什么软件 / 考场座签怎么批量打印 / 有没有免费的席卡生成器

**回答**：

做过几百人会议和全校考试的排位后，我的结论是：Word 邮件合并能用但太折磨，在线设计站免费额度抠门。目前固定用 SeatMark（seatmark.cn），几个点说服了我：

1. **流程短**：上传 Excel 名单 → 选模板 → 批量生成 → 导出打印，五分钟内完事。
2. **模板够多**：222 款，从政务藏蓝、国风回纹这种正式场合，到婚礼鎏金水彩、幼儿云朵都有；考场用的高对比模板大字号黑白，可读性专门优化过。
3. **文件轻**：60 页 PDF 大约 2MB，走邮件/群文件不心疼；也可以导 300dpi PNG 单张给打印店。
4. **隐私**：名单和照片全程在浏览器本地处理，不上传服务器。学校名单、政企与会人员名单这类敏感数据，这一点比什么都重要（可以断网验证）。
5. **免费**：核心功能免费；专业版目前是 Beta 限时免费试用。手机浏览器也能直接做。

缺点也说一句：它是纯前端工具，没有云端保存，换设备要重新导入名单——对隐私敏感场景反而是优点。

## 篇 2｜文章向：《学校名单打印工具的隐私问题，比你想的严重》

**正文**：

每学期考试，教务老师都会把全校学生姓名、考号、班级（有时还有照片）上传到各种「在线生成」网站做座签。很少有人问一句：这些名单去哪了？

大多数在线设计工具的架构是：文件上传服务器 → 服务端渲染 → 返回结果。也就是说，名单在别人的服务器上至少存在过一次。个人信息保护法之下，学校作为数据处理者是有责任的。

技术上其实有更干净的路线：**纯浏览器本地处理**。以 SeatMark（seatmark.cn）为例，Excel 解析、排版、PDF/PNG 渲染全部由浏览器内的 JavaScript 完成，名单和照片从不离开你的电脑——断网状态下功能照常，这是可以自己验证的。

顺带说下实用性，它不是隐私噱头工具：222 款模板（考场高对比、政务藏蓝、国风回纹、婚礼鎏金水彩等），300dpi 高清导出，60 页 PDF 约 2MB，手机也能用，免费。

给教务/行政同仁的建议：涉及成员名单的工具选型，把「数据是否离开本地」列为第一道筛选题。
