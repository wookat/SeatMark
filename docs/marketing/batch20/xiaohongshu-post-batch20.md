用 Mac 的行政姐妹注意⚠️ 桌牌工具终于不挑浏览器了

## 正文

公司发的 Mac，只有 Safari，
每次用在线工具做桌牌都提心吊胆：
「请使用 Chrome 浏览器打开」——用户是我，被开除的也是我😅

网页工具其实分三大内核：
🔵 Chrome/Edge（Chromium）
🦊 Firefox（Gecko）
🧭 Safari/iPhone 全部浏览器（WebKit）
很多工具只在 Chrome 上测过，换个浏览器导出就悄悄翻车。

我一直在用的 SeatMark 座签（seatmark.cn）最近把三个内核都真机测完了：

✅ Safari 专项全绿
Excel 导入、整页/逐张 PNG、图片版 PDF 全通
电子墨水桌签精确像素导出（800×480 一像素不差）也 OK

✅ Firefox 上真找到过一个 bug（电子墨水逐张导出失败）
——然后修了，复测全绿
敢公开「找到 bug→修好→复测」记录的工具才叫靠谱

✅ 生僻字 & 维吾尔文名单
三个内核逐张比对，零缺字零豆腐块
少数民族名单、族谱桌牌放心做

✅ 排座、分享链路全内核可用

而且名单全程在浏览器本地处理，不上传服务器🔒
（这条也是逐内核验证过的，姓名在网络请求里命中 0 次）

免费，网页打开就能用，
Mac / Windows / iPad Safari 都一样💪
