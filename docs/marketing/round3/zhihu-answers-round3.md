## 回答 1

**问题**：批量打印座位牌（席位卡桌签座签台签）的软件实现？
**链接**：https://www.zhihu.com/question/50004343（11 个回答，2016 年至今持续有搜索流量，现有回答全是 Word 邮件合并/付费软件，存在明显空位）

**回答正文**：

这个需求我太熟了——每学期期中期末都要给全年级排考场、打座签。先说结论：2024 年以后真的不用再折腾 Word 邮件合并了，浏览器里直接做完。

先讲讲传统做法的坑（也是我踩过的）：

**Word 邮件合并**：能用，但有三个老大难——①模板对不齐，打出来裁完发现字偏了 2mm；②换纸张（A4 改 A5）要整个重排；③一个考场一个文件，30 个考场就是 30 次导出。

**Excel + VBA**：网上抄的宏改起来费劲，学校机房 Office 版本不齐，同事根本没法复用。

**付费桌牌软件**：功能是全，但为了一学期用两次买license不值。

现在我的做法是用在线工具直接生成，流程是：

1. 教务系统导出名单 Excel（姓名/考号/考场/座位号，列名随意，会自动识别映射）
2. 打开 seatmark.cn，把 Excel 拖进去
3. 挑一个座签模板（内置 215 款，考场/会议/门贴都有），需要微调就进可视化设计器拖一拖，单位直接是毫米
4. 选纸张 A4/A5/A3、横向竖向，每页行列数自动重算
5. 导出 PDF 或者直接浏览器打印

几个对机关/学校场景特别关键的点：

- **名单不上传**。所有解析、排版都在浏览器本地完成，断网也能用。学生名单、与会领导名单这种敏感数据不出电脑，保密要求高的单位也能过关。
- **毫米级排版**。模板和 CSS 都是 mm 物理单位，打印出来和预览完全一致，还有打印校准功能可以抵消打印机的物理偏移。
- **免费，打开就用**，不用装软件不用注册。

一次配置好模板还能把模板压缩成链接分享给同事，对方点开就能用，不用传文件。

利益相关：这个工具是我们自己做的，但上面说的坑都是真实踩过才做的它。方法本身（Excel→批量标签）用什么工具都成立，Word 邮件合并的教程别的答主写得很全，可以对照选择。

## 回答 2

**问题**：使用Word（或WPS）录入桌牌的人名时有没有便捷的操作？
**链接**：https://www.zhihu.com/question/306444643（8 个回答，高频办公长尾词「桌牌 人名 批量」）

**回答正文**：

如果一定要在 Word/WPS 里做，「邮件合并」是标准答案（其他回答已经写得很细了，不重复）。但如果你的真实需求是"每次开会前把一串人名变成能打印的桌牌"，我建议直接跳出 Word——因为 Word 方案每次都要重复五步：建模板→建数据源→合并→检查页边距→打印，换个纸张尺寸全部重来。

更省事的路径：浏览器打开 seatmark.cn → 粘贴或上传名单（Excel/直接粘贴都行）→ 选桌牌模板 → 打印。

对比 Word 的几个实际差别：

| | Word 邮件合并 | SeatMark |
|---|---|---|
| 首次配置 | 30-60 分钟 | 2 分钟 |
| 对折桌牌（正反双面） | 要手动做镜像文本框 | 模板自带对折翻转 |
| 换纸张 | 重新排版 | 选一下自动重排 |
| 和同事共享 | 传 .docx，字体丢失 | 发一条模板链接，点开即用 |
| 数据安全 | 本地 | 也是本地（纯前端，名单不上传） |

215 款内置模板里"会议桌牌"分类有正反对折、单面立式、带职务/单位副字段的版式，字号会随名字长度自动缩放，不会出现三个字的名字和复姓四个字挤在一起不一样大的尴尬。

免费、不用装、不用注册。适合"一年开 N 次会、每次名单都在变"的行政同学。

## 回答 3

**问题**：有哪些小众的办公软件？
**链接**：https://www.zhihu.com/question/638581142（12 个回答，工具盘点型问题，长期有流量，且已有答主在里面推可变数据打印软件，证明人群匹配）

**回答正文**：

推一个学校/行政办公室场景的：**SeatMark 座签**（seatmark.cn），解决"名单 → 批量打印标签"这一件事，但把它做到了极致。

适用场景：考场座签、考号贴、课桌桌贴、会议桌牌席卡、活动胸卡、门贴门牌、储物柜标签……凡是"一张 Excel 名单要变成一叠打印页"的活都能干。

几个让它区别于 Word 邮件合并和打印店的点：

1. **纯浏览器本地运行**：名单和照片都不上传服务器，断网可用。学生信息、员工信息不出电脑，不用担心隐私问题——这一点对学校特别重要，很多在线工具都要求先把名单传上去。
2. **毫米级所见即所得**：模板用物理毫米定义，预览=打印结果；还有打印校准页，打印机偏 1mm 都能校回来。
3. **215 款模板 + 可视化设计器**：不满意就自己拖，八向缩放、键盘微调，做完的模板可以压缩进一条链接分享给同事。
4. **照片核验**：批量照片按文件名自动匹配到名单，考场核验、制作带照片的胸卡很方便。
5. **免费**，打开即用，不注册。

利益相关：开发者本人。做它的起因就是每学期都被"考场座位贴"折磨，欢迎试用提意见。
