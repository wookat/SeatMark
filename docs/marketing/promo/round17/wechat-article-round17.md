## 标题：一个免费桌牌工具的四个「较真」细节：AI 排版、反馈直达、全键盘可用、坏页零交付

**正文**：

批量做桌牌、座签、课桌贴这件事，市面上工具不少，真正拉开差距的往往是细节。这篇介绍 SeatMark 座签（www.seatmark.cn ，免费、无需注册）最近上线的四个能力，每一条都有实测背书，如实说清边界。

### 一、不会排版？让 AI 先排一版

设计器里新增「AI 自动设计」：用一句话描述需求，比如"正式考务桌贴，姓名大字，考场号和座位号放下方"，AI 会直接生成字段布局，你在画布上微调即可。

两点如实说明：

- 免费通道依赖公共模型服务，**限量且不保证可用**，繁忙时段可能失败——失败可稍后重试，或在「自定义 API」里填自己的 API 密钥，稳定性好得多；
- 隐私边界清晰：AI 只收到**字段名与示例值**，完整名单不会被上传。

### 二、反馈直达：右下角一个按钮，直通开发团队企微群

每个页面右下角有浮动反馈按钮，选类型、写内容、留联系方式（可选），提交后直接推送到开发团队的企业微信群。对使用者来说，遇到问题不用去找客服入口；对产品来说，反馈链路越短，修得越快。

### 三、键盘-only 全流程可用：无障碍不是口号

第 208 轮专项走查（全部通过）验证了不碰鼠标也能走完全流程：

- 首页第一个 Tab 就是可见的「跳到主内容」跳转链接；
- 模板页可用键盘搜索、选卡片、进详情；
- 设计器下拉框支持方向键移动、Enter 选中、Esc 关闭并归还焦点;
- 导出对话框有焦点锁定（Tab 不会跑出弹窗），Esc 关闭后焦点回到原按钮；
- 全键盘可完成导出，全程无键盘陷阱。

这对依赖读屏器或仅用键盘操作的用户是刚需，对普通用户的批量操作也更高效。

### 四、坏页零交付：宁可报错，不给坏页

批量导出最隐蔽的坑是**偶发截断坏页**——一批几十页里混一两张右半边空白的，打印完才发现。SeatMark 的三层防线：

1. 预览与导出同链路渲染，导出引擎版本经逐版本回归验证后锁定，所见即所得；
2. 整页导出逐页做截断检测，发现问题自动重新渲染；
3. 持续截断则**直接报错终止**，把问题明确告诉你——绝不静默交付坏产物。
